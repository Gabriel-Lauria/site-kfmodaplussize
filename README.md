# Template de site para lojas de moda

Next.js (App Router) + Tailwind v4 + motion + lenis.

- **Novo cliente:** veja [TEMPLATE.md](TEMPLATE.md) (`npm run novo-cliente`).
- **Desenvolvimento:** `npm run dev` → http://localhost:3000
- **Produção:** `npm run build` e `npm start`

Dados do cliente atual em `config/`, marca e fotos em `public/brand/`, paleta no topo de `app/globals.css`.
